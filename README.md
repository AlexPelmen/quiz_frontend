# Music Quiz

Игровой клиент и админка на React, TypeScript, Ant Design и TanStack Query. Работают с HTTP API
Music Quiz. Для игры и управления используются общие учётные записи и сессия; пользователей создают в админке. Исходники backend для сборки не нужны.

## Разработка

Node.js 22.12+ и npm. Запустите backend на 127.0.0.1:8080, затем:

```powershell
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173/play для игры или http://127.0.0.1:5173 для управления. Vite проксирует /api и /ready; CORS на backend не требуется.
Адрес сервера разработки настраивается в vite.config.ts.

## Docker

```powershell
docker compose up -d --build
```

Игровой клиент доступен на http://127.0.0.1:3000/play, админка — на http://127.0.0.1:3000. Nginx проксирует API к
`host.docker.internal:8080`; через API_UPSTREAM можно указать другой upstream.
Для совместного запуска в одной Docker-сети используется имя сервиса `api:8080`.

## Игра

Откройте готовый пакет и нажмите «Начать». Перед каждым раундом клиент показывает правила.
В конце игры клиент показывает долю правильных ответов в очках от 0 до 100 и звание. Итог и звание рассчитываются локально.
В раунде «Только гласные» буквы в подсказке строчные, согласные пропущены.
При входе можно разрешить автоматическое воспроизведение фрагментов или продолжить без звука.
Если браузер блокирует автовоспроизведение, запустите фрагмент кнопкой на вопросе.
После показа ответа отметьте «Угадали» или «Не угадали», чтобы перейти дальше. В конце раунда
клиент показывает счёт и сохраняет отметки. При ошибке можно повторить сохранение без двойного начисления.

- **← / →** — предыдущий или следующий экран игры, включая заставки раундов.
- **↓ / ↑** — показать или скрыть ответ на текущий вопрос.
- **Пробел** — поставить фрагмент на паузу или продолжить воспроизведение.

Клиент читает пакеты из `/api/v1/quiz-packs`, изображения из `/api/v1/downloads/{id}/file` и
фрагменты из `/api/v1/quiz-packs/{id}/questions/{number}/audio`. Карточки ответов используют
изображения исполнителей и обложки альбомов из каталога.
В раунде «Лицо альбома» клиент получает готовую обложку с масками через маршрут вопроса `…/questions/{number}/cover`.
Результат записывается через `POST /api/v1/quiz-rounds/{id}/results`.

## Управление

- Карточки исполнителей, альбомов и треков с изображениями, аудио и списками связанных записей.
- Прослушивания YouTube Music, подписчики исполнителя и доля правильных ответов. Видны пропуски данных и исключение из квиза.
- В разделе «Модерация обложек» закройте надписи прямоугольниками и сохраните решение: добавление маски автоматически выбирает «Разрешить в раунде». Обложку без подсказок можно разрешить вручную. После замены файла новую обложку нужно проверить снова.
- «Случайный порядок» показывает по одной обложке каждого исполнителя перед повторениями. «Перемешать снова» задаёт новый порядок и возвращает на первую страницу.
- Справочник тегов для исполнителей, альбомов, треков и пакетов: создание, переименование и удаление неиспользуемых тегов.
- Сортировка каталога по заголовкам столбцов, поиск исполнителя по названию, фильтры треков по альбому, исполнителю и статусу аудио.
- Ручное добавление и редактирование записей, замена изображений и MP3 через форму редактирования, удаление с подтверждением.
- Отдельные запуски YouTube Music, Genius и MusicBrainz с описанием данных под каждой кнопкой. В таблице и журнале видны заполненные поля, новые альбомы и треки, ошибки запросов и причина остановки.
- Фильтры каталога «Частично» и «Ошибка» позволяют найти записи для проверки и ручного заполнения.
- Последний известный лимит Genius в шапке и проверка лимита по кнопке.
- На странице «Загрузки» отметьте нужные строки и запустите YouTube Music, Hitmo, Genius + YouTube, Genius Short или изображения. Готовность и ошибки обновляются автоматически. Доступен запуск по прямой ссылке. Прогресс очереди отсчитывается от запуска и сохраняется в браузере отдельно для музыки и изображений.
- На странице исполнителей можно добавить список имён и ссылок на каналы YouTube или YouTube Music. Записи разделяются строками, запятыми, точками с запятой, вертикальной чертой или табуляцией; парсинг запускается отдельно.
- Генерация и редактирование пакетов; просмотр раундов, отрывков и ответов.
- При создании пакета можно загрузить обложку, выбрать сложность, количество вопросов (от 10 до 100 с шагом 10) и типы раундов. Типы перемешиваются и при необходимости повторяются.
  Сложность задаёт центр отбора в ранжированном списке: начало списка для лёгкой, 35% для средней и 80% для сложной.
- В «Настройках» доступны число повторов запроса, порог остановки парсинга, переключатель учёта правильных ответов и порог показов. Остальные параметры доступны в JSON.

Полная запись проигрывается в медиатеке, фрагмент вопроса — в карточке квиз-пакета.
Проверки: `npm run build`, `npm run lint`. Версии зависимостей фиксируются package-lock.json.
