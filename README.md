# Music Quiz

Игровой клиент и админка на React, TypeScript, Ant Design и TanStack Query. Работают с HTTP API
Music Quiz; авторизации нет. Исходники backend для сборки не нужны.

## Разработка

Node.js 22.12+ и npm. Запустите backend на 127.0.0.1:8080, затем:

```powershell
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173/play для игры или http://127.0.0.1:5173 для управления. Vite проксирует /api и /ready; CORS на backend не требуется.
Адрес сервера разработки настраивается в vite.config.ts.

## Docker

```powershell
docker compose up -d --build
```

Игровой клиент доступен на http://127.0.0.1:3000/play, админка — на http://127.0.0.1:3000. Nginx проксирует API к
`host.docker.internal:8080`; через API_UPSTREAM можно указать другой upstream.
Для совместного запуска в одной Docker-сети используется имя сервиса `api:8080`.

## Игра

Откройте готовый пакет и нажмите «Начать». Перед каждым раундом клиент показывает правила.
При входе можно разрешить автоматическое воспроизведение фрагментов или продолжить без звука.
Если браузер блокирует автовоспроизведение, запустите фрагмент кнопкой на вопросе.

- **← / →** — предыдущий или следующий экран игры, включая заставки раундов.
- **↓ / ↑** — показать или скрыть ответ на текущий вопрос.
- **Пробел** — поставить фрагмент на паузу или продолжить воспроизведение.

Клиент читает пакеты из `/api/v1/quiz-packs`, изображения из `/api/v1/downloads/{id}/file` и
фрагменты из `/api/v1/quiz-packs/{id}/questions/{number}/audio`. Карточки ответов используют
изображения исполнителей и обложки альбомов из каталога.

## Управление

- Создание и редактирование исполнителей, тегов, состава и Points; удаление с подтверждением.
- Каталог альбомов и треков, фильтрация, редактирование оценок, ручное добавление.
- Запуск парсера, список запусков, отдельная страница ошибок и перевод исполнителя в ручной режим.
- Последний известный лимит Genius в шапке и проверка лимита по кнопке.
- Загрузки с автообновлением, ручные ссылки на источники, повторы ошибок, аудиоплеер и изображения.
- Генерация и редактирование пакетов; просмотр раундов, отрывков и ответов.
- Редактирование конфигурации сервиса и JSON-консоль для всех методов API.

Полная запись проигрывается в медиатеке, фрагмент вопроса — в карточке квиз-пакета.
Проверки: `npm run build`, `npm run lint`. Версии зависимостей фиксируются package-lock.json.
