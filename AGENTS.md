# Frontend Music Quiz

Самостоятельный React + TypeScript + Ant Design репозиторий. Все команды выполняются здесь.

## Команды

- `npm ci` — установка по package-lock.json.
- `npm run dev` — Vite на 127.0.0.1:5173 с прокси к API на 8080.
- `npm run build` — строгая проверка TypeScript и production-сборка.
- `npm run lint` — ESLint и правила React Hooks.
- `docker compose up -d --build` — самостоятельный Docker-запуск на порту 3000.

## Соглашения

- Используйте функциональные компоненты и строгие типы TypeScript. Не используйте any без причины.
- Формы, таблицы, диалоги и уведомления берите из Ant Design; избегайте собственных дубликатов компонентов.
- Серверные данные храните в TanStack Query, локальное состояние — в React. Инвалидируйте кеш после изменений.
- HTTP-вызовы выполняются через src/api.ts. Используйте относительные /api/v1 URL, а не адрес backend в компонентах.
- Показывайте состояния загрузки, пустых данных и ошибок. Фоновые обновления не должны сбрасывать ввод формы.
- Для удаления используйте подтверждение. У кнопок с одной иконкой должно быть доступное имя.
- Компоненты группируются по задачам пользователя. Не создавайте универсальные слои ради гипотетического переиспользования.
- Проверяйте основное пользовательское действие, ошибки API и узкий экран после изменений интерфейса.
- Не импортируйте файлы из соседнего backend. Контракт — HTTP; поддерживаемая конфигурация описана в README.
- Не храните секреты в VITE_*: они доступны браузеру. Токен Genius принадлежит backend.
- Не делайте commit/push без разрешения пользователя.
